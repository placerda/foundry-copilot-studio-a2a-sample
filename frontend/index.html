How the agents collaborate

Foundry routes your question. When a capability matches, it asks Copilot Studio for an evidence-backed answer.

How this browser reaches the private agents

Your browser sends the question to the local Python requester. The requester uses authenticated APIM to reach private Foundry, then Copilot Studio.

Cloud connections use A2A 1.0 / JSON-RPC 2.0 over HTTPS. The requester provides access, not a separate conversational agent.
