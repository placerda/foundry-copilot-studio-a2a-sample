How the agents collaborate

The private Foundry Router discovers capabilities in API Center and selects one specialist: Copilot Studio for supplier terms, or a Foundry Prompt Agent for logistics. Both routes use APIM.

How this browser reaches the private agents

Your browser sends the question to the local Python requester. The requester uses authenticated APIM to reach private Foundry. The Router reads API Center for each request and calls one matching specialist through APIM, without a static fallback.

Cloud connections use A2A 1.0 / JSON-RPC 2.0 over HTTPS. The requester provides access, not a separate conversational agent.
